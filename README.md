## 🚀 About The Project

**Legal Contract AI Auditor** automates contract review using **Google Gemini AI**. Upload any contract and get a detailed risk assessment with severity scores, priority actions, and comprehensive reports.

**Why use it?**
- ⏱️ **Save Hours**: Manual review takes hours → AI does it in seconds
- 🎯 **Consistent**: Same rules applied every time
- 📊 **Data-Driven**: Quantitative risk scores and trends

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📄 **Universal Documents** | Word, PDF, Excel, PPT, Images, Text |
| 🤖 **AI Analysis** | 10+ risk rules with severity scoring |
| 📊 **Risk Dashboard** | Visual metrics and charts |
| 📥 **Export Reports** | JSON, CSV, Markdown |
| 📧 **Email Reports** | Send reports via email |
| 🔄 **Contract Comparison** | Compare two contracts side by side |
| 💬 **Chat with Contract** | Ask questions about your contract |
| 📋 **Copy Summary** | One-click text copy |
| 📈 **Risk Trends** | Track risk score history |
