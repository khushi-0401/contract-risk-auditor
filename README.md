# ⚖️ Legal Contract AI Auditor

AI-powered contract analysis tool that identifies risks and provides actionable suggestions.

## ✨ Features

- 📄 **Universal Document Support**: Word, PDF, Excel, PowerPoint, Images, and more
- 🤖 **AI-Powered Analysis**: Uses Google Gemini for intelligent risk assessment
- 📊 **Detailed Reports**: Executive summary, risk scoring, and actionable suggestions
- 📥 **Export Options**: JSON, CSV, and Markdown reports
- 📧 **Email Reports**: Send audit reports via email
- 🔄 **Contract Comparison**: Compare two contracts side by side
- 💬 **Chat with Contract**: Ask questions about your contract
- 📋 **Copy Summary**: One-click summary copy
- 📈 **Risk Trend Chart**: Track risk score history
